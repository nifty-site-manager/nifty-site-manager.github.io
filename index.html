Small by design

Add project awareness without handing over the stack.

Nift tracks outputs, composes reusable source, resolves checked paths and rebuilds through explicit dependencies. The rest of the website can stay ordinary web technology.

□

Templates without a takeover

@content and @input are enough to remove duplicated layouts and reusable fragments from an ordinary website.

↪

Easy to adopt

Start with an existing HTML site, extract the pieces that repeat, and let Nift build the same frontend. A migration does not need to become a rewrite.

▱

Dependency aware

Included files become dependencies automatically, so changing a shared partial can rebuild the pages that actually use it.

↯

Built for speed

Written in C++ with fast full and incremental builds, Nift stays comfortable as projects grow.

♡

Use the wider ecosystem

npm, TypeScript, React, Vue, Svelte, Tailwind, Go, C++, APIs and image tools remain themselves. Nift does not need a special version of everything.

◇

Checked relationships

Paths, inputs, data and project contracts can turn important assumptions into build-time failures instead of broken output discovered later.

Fast feedback, explainable builds

Do less work when less changed.

Nift is a native, multithreaded build tool with dependency-aware incremental modes. The important part is not just benchmark speed: it is keeping everyday rebuild work proportional to the change.

01

Native executable

No project-local runtime dependency tree is required just to compose pages and inspect build state.

02

Dependency-aware

Inputs, explicit dependencies, checked paths and project contracts contribute to an explainable build graph.

03

Incremental by design

Change one page and keep the work local. Change shared source and rebuild the outputs that depend on it.

04

Plain deployable output

If the site does not need a client framework, Nift does not make you ship one. Generated HTML can simply be HTML.

Human-first, AI-friendly

A small build model is easier for people and agents to reason about.

Nift is designed first for humans. The same properties—ordinary files, explicit relationships, fast validation and a compact language—also make it unusually comfortable to use with coding assistants.

A short project context can teach the Nift-specific layer; most implementation work remains HTML, CSS, JavaScript, TypeScript and the stack you already chose.
