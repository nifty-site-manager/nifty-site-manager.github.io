Privacy

Privacy on nift.dev

nift.dev is primarily a static documentation website. It does not require an account to read the site and the current site source does not include advertising, behavioural analytics, tracking pixels or a first-party application API.

Local browser state

The website stores your selected colour-theme preference in browser localStorage so light, dark or system mode can persist across visits. That value stays in your browser and is used only to choose the site appearance.

External services

Links to GitHub, package managers, hosting providers and other third-party resources take you to services with their own privacy practices. nift.dev cannot control what those external sites collect once you leave this domain. The site may also be served through hosting/CDN infrastructure that necessarily processes ordinary HTTP connection data such as IP addresses and request headers to deliver pages.

No hidden account or API data collection

Nift itself is a local command-line build tool. Reading nift.dev does not create a Nift account or send project source files to a Nift-hosted backend. Documentation may demonstrate APIs and server integrations, but those examples describe architectures you can build with Nift; they are not data-collection endpoints operated by nift.dev.

If the site later adds analytics, forms, accounts or another data-processing feature, this page should be updated before that feature is presented as part of the public site.
