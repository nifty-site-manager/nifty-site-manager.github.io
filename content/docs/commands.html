Commands.

This page is matched against the current v0.3/v4 command dispatcher. It documents every accepted command, the aliases implemented by the binary, and the argument forms the current code recognises.

Commands that work anywhere

nift version

Prints the installed Nift version.

nift version

nift help / nift about

Displays a short description of Nift, the official website/source locations and the installed version, then points you toward nift commands.

nift help
nift about

nift commands / nift cmds

Prints the command summary compiled into the executable.

nift commands
nift cmds

Initialise a project

nift init [output-extension]

Initialises Nift in the current directory. With no argument it defaults to .html. When an extension is supplied it must begin with a full stop.

nift init
nift init .html
nift init .txt

An HTML initialisation creates the project config/tracking files, starter HTML/CSS/JS templates, initial tracked items and an initial build.

nift init-html

A compatibility spelling accepted by the current dispatcher. The source explicitly marks it as removable after older package-manager tests are updated, so new documentation uses nift init .html.

Inspect project state

nift status [display-option]

Lists updated/problem files. The current dispatcher accepts one optional display mode:

-a  -ab  -ap  -abp  -b  -bp  -n  -p
nift status
nift status -p

nift info name...

Shows information for one or more tracked names.

nift info about
nift info about docs/getting-started

nift info-all

Lists watched directories and tracked files.

nift info-names

Lists tracked names.

nift info-tracking

Lists tracked file information.

nift info-watching

Lists watched directories.

nift info-all
nift info-names
nift info-tracking
nift info-watching

Track and manage items

nift track name [title] [template]

Tracks a new item. If the title is omitted Nift derives one from the name. If the template is omitted the project-wide default template is used.

nift track about
nift track about "About us"
nift track about "About us" templates/template.html

nift untrack name

Stops tracking the named item and removes its generated output/tracking information while keeping the content file.

nift untrack old-page

nift rm name / nift del name

Removes a tracked item including its generated output and its content file. del is an implemented alias, so use this command deliberately.

nift rm obsolete-page
nift del obsolete-page

nift mv old-name new-name / nift move old-name new-name

Moves/renames a tracked item to a new tracked name.

nift mv docs/install docs/getting-started

nift cp tracked-name new-name / nift copy tracked-name new-name

Copies a tracked item and its content to a new tracked name.

nift cp blog/post-template blog/new-post

Build

nift build

The everyday shorthand. With no names—or with one leading option argument—it dispatches to build-updated. With tracked names it dispatches to build-names.

# Build outputs affected by changes
nift build

# Same updated-build path with a display mode
nift build -p

# Build particular tracked names
nift build about docs/getting-started

nift build-updated [display-option]

Checks the project and builds outputs Nift considers updated. It accepts the same current display modes as status:

-a  -ab  -ap  -abp  -b  -bp  -n  -p
nift build-updated
nift build-updated -p

nift build-names [option] name...

Builds explicitly supplied tracked names. The current v0.3 dispatcher recognises a leading -s or -n form before the names.

nift build-names about docs
nift build-names -n about docs

nift build-all [option]

Builds every tracked output. The current implementation accepts -p or -n as its optional display mode.

nift build-all
nift build-all -p
nift build-all -n

nift build-auto [sleep-seconds|-s]

Runs Nift's automatic updated-build loop. A numeric argument sets the sleep interval between checks in seconds. The current dispatcher also recognises -s as its non-interactive/alternate auto-build mode.

nift build-auto
nift build-auto 0.5
nift build-auto -s

Watch content directories

nift watch dir [content-ext] [template] [output-ext]

Adds a watched mapping for a directory under the configured content directory. The watched directory must exist and end in / or \. Optional content/output extensions must begin with .; an explicitly supplied template must exist.

nift watch content/blog/
nift watch content/blog/ .md
nift watch content/blog/ .md templates/blog.html
nift watch content/blog/ .md templates/blog.html .html

nift unwatch dir [content-ext]

Removes a watched directory/content-extension mapping. If the content extension is omitted, Nift uses the project's default content extension.

nift unwatch content/blog/
nift unwatch content/blog/ .md
