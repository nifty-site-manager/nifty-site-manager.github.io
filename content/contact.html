Contact

Contact and project support

Nift is an open-source software project rather than a hosted service with a sales or support desk. The most reliable contact routes are the public project channels where questions and fixes can stay attached to the code they concern.

Questions, bugs and feature requests

Use the Nift GitHub issue tracker for reproducible bugs, compatibility problems, documentation defects and concrete feature requests. Include the Nift version, operating system, relevant project configuration and a minimal reproduction when possible.

Source and releases

The canonical source repository is github.com/nift-dev/nift. Published release artifacts and release notes live with that repository. Installation instructions on nift.dev point to the supported distribution channels.

Documentation questions

If the documentation is unclear or wrong, treat that as a project issue rather than silently working around it. Nift intentionally keeps its project model small, so unclear behavior should be made explicit in the docs or tests. For agent-assisted work, start with HANDOVER.md and the AI assistants guide.

This page does not invent a phone number, postal address or private support mailbox simply to look more corporate. Public project channels are the current authoritative contact mechanism.
